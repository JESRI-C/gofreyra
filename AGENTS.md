- Own drone photos render via `photoProps()` from src/lib/photo-variants.ts (pre-generated 800/1400 px WebP and 1200x630 share JPEG on the asset CDN); new photos need variants uploaded and added there, because the asset pipeline does not resize at build time.
- Viden and Ordbog consumers use the aggregate lists in src/data/content.ts; add future batches only there so hubs, links and sitemap stay synchronized. Fact-checked data text must remain unchanged except for explicit client-supplied corrections.
- Sitemap content entries use their own updated field; static pages omit lastmod without an authoritative page-specific timestamp.
- Public pages live under `src/routes/{-$locale}/` (Danish unprefixed, /en and /de); internal links use `LLink` so the chosen language is kept, and page copy lives per locale in `src/i18n/pages/` so translations stay static and reviewable.
- EN/DE article, term and service data live in `src/data/i18n/` with the same slugs, sources and links as the Danish originals; every new Danish batch needs matching en/de files wired through `artiklerFor`/`termerFor` in src/data/content.ts.
- Freyra Group sister brands are listed only in `src/data/brand-family.ts` and rendered by `BrandFamily` in Header and Footer, so a new brand is added in one place and only once it has a live URL.
- Brand artwork is rendered only through `src/components/site/brand.tsx` from the exact supplied SVG files (logos as CDN pointers, small motifs as byte-identical copies in `src/assets/brand/`), so marks are never redrawn; colour, radius and type tokens live in `src/styles.css` and decisions are recorded in `.lovable/brand-reference.md`.
- Page heroes use `PageHero` and section intros `SectionHeader` from `src/components/site/sections.tsx`, so the editorial layout stays consistent across all locales.
